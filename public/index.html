Calculation performance

Uses one calculation worker for all driver entries, reducing memory use. It may find fewer improvements within the same time limit. Default: up to two workers. Restoring the second worker may need an internet connection. Reset keeps this choice until the page is reloaded.

Waiting for the calculation engine.

Stores calculated setup scores in memory so the search can reuse them, separately for each driver and tyre compound. The search can test more setups than this limit. Best results are kept when older cached scores are discarded.

Lower limits can reduce memory use but may repeat lap calculations. Higher limits can retain more scores and may reduce repeated work. Default: 4,096; enter a whole number from 100 to 100,000.

Advanced search settings

The time limit covers the search only. Preparing reference setups takes extra time.

For each result, refinement starts at its first S+. Only newly calculated laps count towards the lap limits. A total gain of 0.01 points resets the no-improvement count.

A batch is a group of candidate settings. After S+, the batch limit stops repeated work with no new laps or 0.01-point gain. Limits are checked between batches, so they can be exceeded slightly. Stop keeps completed results.

How to read these estimates

Grades use the selected pace and driver-preference weights; the default is 85% pace and 15% preference. Custom weights change the optimiser's grades. S+ starts at 98/100. AVG_DRY uses one shared setup and scores it separately on soft, medium and hard tyres.

Pace compares the predicted lap with a reference lap for the same driver and compound. Driver preference measures how closely balance and traction match the driver's wishes.

Uses each driver's fitted parts, saved development, part understanding and chassis limits. Future upgrades are not predicted. Supported saves need Formula entries, standard car rules and complete fitted-part data.

Lap estimates use fresh, fully warmed tyres and the selected fuel, pace and engine mode. The defaults are 15 kg fuel, medium pace and medium engine. Fuel stays constant during each estimated lap. Traffic, tyre wear, failures and DRS are excluded.

ERS follows the saved rules: fitted equipment for open development, the standard unit for spec rules, or none when banned. Enabled ERS uses balanced deployment and starts each lap charged. Saved tyre-supplier ratings and contract grip bonuses are applied.
